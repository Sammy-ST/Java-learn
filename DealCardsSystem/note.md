## 一、项目整体认知
本次我完成Java斗地主简易实战，核心实现**造牌、洗牌、发牌、手牌排序、展示牌面**五大功能，一共拆分三个类分工协作，逻辑清晰好理解。
1. **Card卡牌类**：封装单张牌的属性与行为
2. **Room房间类**：实现游戏核心业务逻辑
3. **Game启动类**：程序入口，启动游戏即可运行

## 二、Card卡牌类编写学习
### 1. 成员变量
我定义两个私有属性，分别存储牌的点数、花色，私有成员只能本类访问。
```java
private String size;  // 点数：3~2、小王、大王
private String color;  // 花色：黑桃、红桃、梅花、方块
```

### 2. 构造方法
1. 无参构造：空创建卡牌对象，后续用set方法赋值
2. 有参构造：创建卡牌时直接传入点数、花色赋值
只要手写任意构造方法，编译器就不会自动生成默认无参构造，所以我手动补上无参构造。

### 3. Get&Set方法
私有变量外部无法直接获取修改，我提供公开存取方法，用来读写牌的点数和花色，排序时需要调用getSize获取点数。

### 4. toString重写
直接打印对象默认输出内存地址，看不懂牌面。
我重写toString方法，指定输出格式为**花色+点数**，打印集合就能直观看到扑克牌样式。

## 三、Room房间类核心逻辑学习
### 1. 全局牌容器
创建集合存放全部54张扑克牌，整个房间共用这一副牌。
```java
private List<Card> cards=new ArrayList<>();
```

### 2. 程序入口start方法
按游戏顺序执行流程：造牌→打印初始牌→洗牌→打印洗牌后牌→执行发牌逻辑。

### 3. prepareCards造牌方法
1. 定义点数数组、花色数组
2. 双层循环遍历组合，生成52张普通扑克牌存入集合
3. 单独添加小王、大王两张特殊牌，凑齐完整54张牌

### 4. shuffleCards洗牌方法
使用集合工具类`Collections.shuffle(集合)`，直接打乱集合内元素顺序，模拟真人洗牌效果，方法会直接修改原牌堆。

### 5. dealCards发牌方法
1. 创建三个玩家手牌集合、一个底牌集合
2. 遍历全部牌堆，通过`cards.get(i)`获取下标为i的单张牌
3. 下标判断：**i >= 总牌数-3**，最后三张牌判定为底牌
4. 余数轮流发牌：利用`i%3`取余，0、1、2依次分给三个玩家，实现轮流发牌
5. 发牌结束调用排序方法，规整玩家手牌
6. 分别打印三个玩家手牌、底牌，直观查看发牌结果

### 6. sortCard手牌排序方法
1. 形参接收单个玩家的手牌集合，通用排序逻辑可复用给所有玩家
2. 自定义扑克牌大小顺序数组，规定牌的权重
3. 使用`Collections.sort`结合Lambda表达式排序
4. `(c1,c2)`代表每次两两对比的两张卡牌
5. 循环匹配两张牌的点数，获取对应权重下标
6. 下标相减实现从小到大排序，下标越小牌越小

## 四、Game启动类
极简入口类，只负责创建房间对象，调用启动方法，一键运行整个斗地主程序。

## 五、重点知识点总结
1. **可变参数&集合工具**：`Collections.shuffle`打乱顺序，`Collections.sort`实现集合排序
2. **集合取值**：`集合.get(下标)`，根据索引获取指定元素
3. **对象打印**：重写toString方法，自定义对象输出样式，避免打印内存地址
4. **构造方法规则**：手写构造后不再自动生成默认无参构造
5. **轮流分配逻辑**：`下标%人数`取余数，实现轮流分发数据
6. **Lambda排序**：简化比较器写法，两两对比元素完成自定义规则排序

## 六、踩坑记录
1. 发牌边界判断最初用`>`，漏掉一张底牌，修正为`>=`才能完整截取最后三张
2. 初期未写toString，打印一堆内存地址，重写后正常显示牌面
3. 卡牌类缺少getSize方法，排序无法获取点数，补全getter方法解决报错
4. 手写有参构造后无参构造失效，手动添加无参构造避免创建对象报错

## 七、整体运行流程
启动程序→自动生成54张牌→打印原始牌堆→随机洗牌→轮流发牌留底牌→玩家手牌自动排序→控制台展示所有人手牌与底牌
