## 一、二维数组基础概念
二维数组本质：**数组中存放一维数组**
- 外层数组：代表**行**
- 内层每个一维数组：代表当前行的**列**

示例：
```java
// 规则二维数组：4 行 4 列
int[][] arr = new int[4][4];
```

---

## 二、arr.length 与 arr[i].length 核心区别
### 1. `arr.length`
- 含义：获取**二维数组总行数**
- 作用：控制**外层 for 循环（遍历行）**
- 原理：统计二维数组里一共有多少个一维数组

### 2. `arr[i].length`
- 含义：获取**第 i 行的列数**（当前行元素个数）
- 作用：控制**内层 for 循环（遍历列）**
- 原理：`arr[i]` 取出第 i 行一维数组，再调用 `length`

---

## 三、关键口诀 & 记忆技巧
- `arr.length` → **看行**
- `arr[i].length` → **看列**
- 外层循环用行，内层循环用列

---

## 四、不规则二维数组高频考点
规则数组：每行列数相同，两种写法暂时通用
不规则数组：**每行长度不一致**
```java
int[][] arr = {{1,2},{3},{4,5,6}};
```
- `arr.length` = 3 （共 3 行）
- `arr[0].length` = 2
- `arr[1].length` = 1
- `arr[2].length` = 3

> 必记：不规则二维数组，内层循环必须写 `arr[i].length`，否则数组越界报错。

---

## 五、二维数组代码优化要点
1. 类名遵循 Java 大驼峰规范
2. 固定数值抽取为常量，方便后期修改
3. 循环写法通用化
   - 行：`i < array.length`
   - 列：`j < array[i].length`
4. 功能拆分：打印、逻辑操作单独封装方法
5. 代码缩进、空格规范，控制台排版对齐

---

## 六、核心易错点总结
1. 不要全部写死数字（如 `i < 4`），扩展性差
2. 不要内层循环误用 `array.length`，不规则数组直接报错
3. 二维数组遍历固定格式：**外层行、内层列**
4. 数组元素交换，必须借助临时变量 `temp`
