## 3. 代码分层功能详解
### 3.1 接口层 Switch
统一规范所有家电都必须具备开关功能，抽取公共行为。
```java
public interface Switch{
    void press();
}
```

### 3.2 父类 JD
1. 实现开关接口，重写按压方法，反转设备状态
2. 私有成员变量：设备名称、开关状态
3. 使用 `@Data` 注解自动生成 `get/set` 方法
4. 作为所有家电父类，实现代码复用

### 3.3 家电子类
继承家电父类，子类构造方法中调用父类`set`方法完成赋值，**不使用super调用父类构造**。

### 3.4 中控类 SmartHomeControl
1. 私有化构造方法，禁止外部随意创建对象
2. 内部创建唯一静态中控实例
3. 提供公开静态方法获取唯一实例
4. 提供单个设备控制、全部设备状态打印两个核心业务方法

### 3.5 主程序 Test
1. 创建家电数组，批量存储所有设备对象
2. 获取唯一中控实例
3. `while(true)` 做成常驻菜单
4. `switch` 匹配用户输入，完成设备控制与退出功能

## 4. 编写过程出现的错误与解决办法
### 错误1：子类调用父类成员变量报错
- 报错信息：`name has private access`
- 原因：父类成员变量被 `private` 私有化，子类无法直接访问
- 解决：子类构造器使用父类`set`方法赋值，不直接访问成员变量

### 错误2：找不到 setName / setStatus 方法
- 原因：忘记在父类添加`@Data`Lombok注解，无法自动生成存取方法
- 解决：导入Lombok依赖，在JD类上方添加`@Data`

### 错误3：增强for循环写法错误
- 错误代码：`for(JD i:devices.length)`
- 错误原因：遍历写成遍历数组长度，类型不匹配
- 解决：改用普通for循环遍历数组下标，正常打印序号与设备状态

### 错误4：父类无对应带参构造报错
- 原因：子类使用`super(参数)`调用父类带参构造，父类未定义
- 解决：放弃`super(有参构造)`，统一使用`set`方法赋值

## 5. 核心难点：单例模式全面解析
### 5.1 单例作用
保证**整个项目中智能中控类只能存在唯一一个对象**，避免多个控制器造成逻辑混乱。

### 5.2 单例三行核心代码
```java
// 1. 私有构造：锁住大门，外部不能new
private SmartHomeControl(){}
// 2. 内部提前创建唯一实例（static全局唯一，final不可修改）
private static final SmartHomeControl INSTANCE = new SmartHomeControl();
// 3. 公开获取方法：唯一对外访问入口
public static SmartHomeControl getInstance(){
    return INSTANCE;
}
```

### 5.3 调用方式
```java
// 不能new，只能通过类名调用静态方法获取
SmartHomeControl control = SmartHomeControl.getInstance();
```

### 5.4 答疑：为什么只有 getInstance 没有 setInstance
1. `final` 修饰实例，常量无法二次赋值修改
2. 单例设计思想：**只允许获取使用，不允许替换修改**
3. 中控是全局统一管理者，业务上不允许重新设置新控制器
4. `get`用于取值使用，`set`用于修改数据，此实例无需修改

## 6. 构造器知识点复盘
### 6.1 无参构造
```java
public 类名(){}
```
创建对象**不赋值**，后期通过`set`方法设置属性。

### 6.2 有参构造
```java
public 类名(参数){}
```
创建对象**直接赋值**，一步完成对象初始化。

### 6.3 私有构造 private 构造
1. **不用于初始化赋值**
2. 唯一作用：**禁止外部 new 创建对象**
3. 多用于工具类、控制类、单例类
4. 本项目中控类专用，和家电赋值构造完全无关

### 6.4 项目使用区分
1. 家电类：使用构造器 / set方法给**设备名称、开关状态**赋值
2. 中控类：使用`private`空构造**禁止创建对象**，不需要任何赋值

## 7. 交互逻辑 while+switch 讲解
1. `while(true)`：死循环，实现菜单重复使用，不用反复运行程序
2. 每次循环先打印当前所有家电状态
3. Scanner 接收用户数字选择
4. switch 分支匹配对应设备，调用中控控制方法
5. 设置0号选项作为系统退出入口
6. default 捕获非法输入，做错误提示
